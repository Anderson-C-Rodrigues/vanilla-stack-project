# 📋 Task Manager

Aplicação web para organização e acompanhamento de tarefas desenvolvida com tecnologias nativas da Web.

O sistema permite criar e gerenciar tarefas, organizá-las em categorias, definir prioridades e prazos e acompanhar o andamento através de diferentes interfaces.

## ✨ Funcionalidades

- Dashboard de acompanhamento
- Criação e edição de tarefas
- Organização por categorias
- Prioridades baixa, média e alta
- Status de tarefa: pendente, completada ou cancelada
- Datas de vencimento
- Descrição detalhada
- Pesquisa de tarefas
- Filtros por categoria, status e prioridade
- Área de relatórios

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript Vanilla

O projeto foi desenvolvido sem frameworks, permitindo trabalhar diretamente com DOM, eventos e lógica JavaScript no navegador.

## 📁 Principais interfaces

```text
index.html        # Dashboard
 tarefas.html      # Gerenciamento de tarefas
categorias.html   # Gerenciamento de categorias
relatorios.html   # Relatórios
```

A aplicação também utiliza arquivos JavaScript separados para persistência, navegação e regras específicas de cada interface.

## 🚀 Como executar

Clone ou baixe o repositório e abra `index.html` em um navegador moderno.

Para uma execução mais consistente durante o desenvolvimento, também é possível iniciar um servidor HTTP local na pasta do projeto:

```bash
python -m http.server 5500
```

Depois acesse:

```text
http://localhost:5500
```

## 🎯 Objetivo

O projeto foi desenvolvido para praticar a construção de uma aplicação web utilizando a Vanilla Stack, trabalhando organização de interfaces, manipulação de dados, filtros, formulários e interação dinâmica com JavaScript.
